SPRING PRACTICALS - COMPLETE SUBMISSION
========================================
This archive contains three independent projects:
1. TiffinSpring       - Spring Core XML, DI, bean scopes and plans
2. GymManagerSpring   - Annotation configuration, Spring JDBC and DAO CRUD
3. GymManagerWeb      - Spring MVC, JSP CRUD, validation, edit/delete/search

Open each project folder separately in Eclipse as an Existing Maven Project.
Use Java 17+. Maven resolves Spring and MySQL dependencies.
For database projects, run each project's sql/gym_db.sql and configure
MySQL credentials in AppConfig.java.

GymManagerWeb requires Apache Tomcat 10.1+ because it uses Spring 6/Jakarta.
Read each project's README.txt for exact run/deployment steps.
